Neon Animated Login & Signup UI
A modern neon-themed animated authentication UI built using HTML, CSS, and JavaScript.
This project focuses on UI/UX, smooth animations, and a premium user experience rather than backend logic.

The goal was simple:
Make a login/signup screen that feels exciting, modern, and memorable.
 Features
 Login & Signup pages with smooth transition animation
 7-color neon glow animation (Pink, Blue, Green, Yellow, Red, Purple, Cyan)
 Show / Hide password (eye toggle)
 Confirm password field in signup
 “Forgot password” option
 Social login UI (Google, Facebook, LinkedIn)
 Animated background with floating neon glow orbs
 Clean, distraction-free UI focused on usability
 Responsive and works on different screen sizes

 
 Technologies Used :
HTML5 – Structure of the UI

CSS3 –
Neon glow effects
Keyframe animations
Animated background
Smooth transitions
JavaScript (Vanilla JS) –
Login ↔ Signup switching
Password eye toggle logic
UI interactivity
No frameworks, no libraries — everything is built from scratch.

* Design & UI Decisions *
Dark background was chosen to make neon colors pop
Slow animations to avoid distraction
Minimal text so users focus on actions
Soft glow instead of sharp borders for a premium feel
Animated background kept subtle so it doesn’t overpower the login card
This UI is inspired by modern SaaS dashboards and fintech applications.


 Advantages  :
  Eye-catching UI (great for portfolios)
 Lightweight (no frameworks)
Easy to understand code
 Fully frontend – safe for demo use
 Can be reused in real projects

⚠️ Limitations / Disadvantages :

 No backend authentication (UI only)
  Social login buttons are visual only
 No form validation or error handling yet
 Not connected to Firebase or any database
(These are intentional and can be extended later.)
